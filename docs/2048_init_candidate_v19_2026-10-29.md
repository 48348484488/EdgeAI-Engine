# EdgeAI V19 — C++ candidate for 2048 initialization (29 Oct 2026)

Scope: **original stripped AArch64 ELF** with SHA-256
`a3ca49d16ca6428291574ebd3f7c54153ef0913f8aa1eee4279408c3bf9d499b`.
The source-blind bounded translator `tools/aarch64_init_chain_lifter.py` produced
`experiments/2048_v19/candidate_401704.cpp` from 21 consecutive ARM64 instructions
at `0x401704–0x401758`. The original C source was not an input.

## What the candidate actually contains

* Two literal `__printf_chk` calls recovered from the ELF's allocated `.rodata`,
  at `0x401a40` and `0x401af0`. Their bytes are terminal escape sequences.
* `time(NULL)` followed by `srand` with the returned low 32 bits.
* An internal call to `0x4011cc` with argument zero (terminal control).
* `signal(2, 0x4016ac)` with an internal callback address.
* Verified balanced 16-byte frame, direct imports resolved against ELF PLT,
  and no unsupported instructions silently skipped.

The generated C++ compiles with
`clang++ -std=c++17 -Wall -Wextra -Werror -fPIC -c`.
A native test harness replacing the six external/internal symbols with deterministic
stubs verified the ordered calls, both literal strings, seed `123456`, argument zero,
signal number two and handler pointer. **This is mocked host-side call-trace validation,
not execution of the original ARM64 routine.**

Ten isolated regression tests passed, including rejection of unknown imports, altered
register arguments, unknown internal callback addresses, unsupported printf formats,
invalid frame, truncated/extra instructions and unknown opcodes.

## Reproduction

```bash
python3 tools/aarch64_init_chain_lifter.py \
  --elf /path/to/2048-arm64-stripped.elf \
  --start 0x401704 --end 0x401758 \
  --expected-sha256 a3ca49d16ca6428291574ebd3f7c54153ef0913f8aa1eee4279408c3bf9d499b \
  --output /tmp/candidate_401704.cpp \
  --report /tmp/init_report.json
python3 -m unittest discover -s tests -p 'test_aarch64_init_chain_lifter.py'
clang++ -std=c++17 -Wall -Wextra -Werror -fPIC -c /tmp/candidate_401704.cpp -o /tmp/candidate_401704.o
```
